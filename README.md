# 🧙‍♂️ ChronoWizard — The Magic of Time

**Every date has a story.**

ChronoWizard is an cool interactive website that challenges users to discover the day of the week for any date. Built as a personal project, it combines calendar calculations with an engaging, magical-themed experience.

🌐 **Live Website:** [chronowizard.com](https://chronowizard.com/)

## ✨ Features

- **Date Calculator:** Find the day of the week for a selected date.
- **Random Date Challenge:** Test your ability to identify weekdays without looking them up.
- **Calendar History:** Account for the transition from the Julian calendar to the Gregorian calendar starting in 1582.
- **Next and Previous Matches:** Explore when a date next falls, or last fell, on the same weekday.
- **Custom Themes:** Personalize the website's appearance.
- **Share Results:** Share date calculations with others.
- **Responsive Design:** Use the website across different devices.

## 🛠️ What was used

- HTML
- CSS
- JavaScript
- GitHub Pages
- Custom domain and DNS configuration

## 🎯 Project Goals

The goal of ChronoWizard was to turn an interest in calendar calculations into an interactive website, a skill I already have, that people can use and share.

This project gave me hands-on experience with website deployment, domain configuration, and publishing a project for public use.
